Convolutional Neural Networks for Dense Prediction

Encoder–Decoder Networks and U-Net

Figure 1 illustrates the canonical U-Net encoder–decoder with skip connections, widely used for dense prediction tasks.

Figure 1 U-Net encoder–decoder architecture (adapted from Ronneberger et al., 2015).

A common way to adapt CNNs for dense prediction is to use an encoder–decoder structure. The encoder progressively downsamples the input to build high-level, context-rich features, while the decoder upsamples these features back to the original resolution to produce a per-pixel output map.

U-Net is a widely adopted encoder–decoder architecture that adds skip connections between matching encoder and decoder stages. These skip connections pass fine spatial detail directly to the decoder, improving localization while preserving global context. Although U-Net was originally introduced for biomedical segmentation, its design is broadly applicable to robotics perception tasks that require pixel-accurate outputs (e.g., grasp quality maps).

In this project, the same encoder–decoder principle is used to predict grasp maps from RGB-D crops, where accurate localization of the grasp center is essential.

Deep residual networks (ResNet) introduce identity skip connections inside residual blocks, allowing the network to learn residual functions. This design improves gradient flow and enables training deeper backbones with better optimization stability.

In many vision pipelines, a ResNet is used as the encoder/backbone because it provides strong multi-scale features. When combined with a decoder (U-Net style), this produces a robust dense prediction network that can capture both global structure and local edges—useful for grasp inference on small objects such as bricks.

Dense grasp prediction is commonly formulated as per-pixel regression/classification, where each pixel encodes the quality of a grasp and its geometric parameters. CNN encoder-decoder designs are a natural fit because they learn multi-scale spatial features and can output maps at the same resolution as the input. U-Net introduced the canonical symmetric encoder-decoder with skip connections that preserve fine spatial detail across downsampling stages [1]. Residual connections (ResNet) improve optimization of deep CNN backbones by learning residual mappings, enabling stronger feature extractors for downstream dense tasks [2].

Transformers replace recurrence and convolution with attention mechanisms that dynamically route information between tokens. In vision, tokens can represent image patches (ViT) or windowed patches (Swin). The key operation is self-attention, where every token computes a weighted combination of other tokens based on content similarity.

Scaled Dot-Product Self-Attention

Given an input sequence of token embeddings X ∈ R^{N×D}, self-attention first forms three projections: queries Q, keys K, and values V. The attention output is computed as:

Attention(Q, K, V) = softmax( (Q K^T) / sqrt(d_k) ) V

Here, d_k is the key dimensionality used for scaling. The matrix A = softmax(QK^T / sqrt(d_k)) contains attention weights; some texts refer to this weight matrix as the relation matrix R. Each row of A sums to 1 and specifies how strongly one token attends to all other tokens.

Query (Q), Key (K), and Value (V) Construction

The Q/K/V tensors are produced by learned linear layers: Q = X W_Q, K = X W_K, V = X W_V, where W_Q, W_K, W_V ∈ R^{D×d}. Intuitively, keys describe what information a token offers, queries describe what information a token seeks, and values carry the content that will be aggregated. Similarity between queries and keys determines the weights applied to values.

Multi-Head Attention

Instead of a single attention operation, multi-head attention splits the embedding into h heads, runs attention independently in each head, and concatenates the results: head_i = Attention(QW_Q^i, KW_K^i, VW_V^i), MHA(X) = Concat(head_1,…,head_h) W_O. Multiple heads allow the model to attend to different patterns (e.g., edges, corners, long-range relations) simultaneously.

Transformer Encoder Block

A standard encoder block contains: (1) LayerNorm → multi-head self-attention → residual connection, followed by (2) LayerNorm → a feed-forward network (MLP) → residual connection. Dropout is often applied for regularization. In vision, stacking these blocks enables global context modeling beyond the receptive field growth limitations of CNNs.

Why Attention Helps for Grasp Prediction

For grasp detection on small objects, local texture cues (edges, contact regions) must be combined with global context (overall object orientation and shape). Self-attention provides an explicit mechanism to exchange information across distant regions, which can reduce ambiguity when multiple candidate grasps exist.

Transformers replace recurrent or purely convolutional processing with self-attention, which learns content-dependent interactions between tokens. Given query (Q), key (K), and value (V) projections, scaled dot-product attention computes soft weights over all tokens and aggregates values accordingly. Multi-head attention runs several attention operations in parallel to capture diverse relationships. This mechanism, introduced in the original Transformer for sequence modeling [9], has since been adapted to vision by treating image patches as tokens.

Vision Transformer (ViT)

Vision Transformer (ViT) adapts the Transformer encoder to images by representing an image as a sequence of patch tokens. Unlike CNNs that use convolutions for locality, ViT relies on tokenization (patch embedding) and self-attention for feature learning.

Patch Extraction and Patch Embedding

An input image I ∈ R^{H×W×C} is split into non-overlapping patches of size P×P. The number of patches is N = (H·W)/(P^2). Each patch is flattened into a vector of length P^2·C and mapped to an embedding dimension D using a learned linear projection (equivalent to a Conv2D with kernel=P and stride=P):

x_p = Flatten(patch_p) ∈ R^{P^2·C},    z_p = x_p E,    where E ∈ R^{(P^2·C)×D}

The resulting token matrix Z ∈ R^{N×D} is the sequence input to the Transformer. For a 160×160 crop with P=16, N=100 tokens (10×10); with P=8, N=400 tokens (20×20). Smaller P increases token count and compute cost but preserves more spatial detail.

Positional Encoding

Because attention is permutation-invariant, ViT adds positional embeddings to encode patch locations. A learnable position vector p_i is added to each patch token: Z̃_i = Z_i + p_i. This allows the model to distinguish tokens by spatial position. Some variants also use 2D relative positional biases.

Class Token vs Dense Outputs

For classification, ViT often prepends a learnable [CLS] token and uses its final embedding for prediction. For dense prediction (segmentation / grasp maps), the model instead preserves per-token features and upsamples or decodes them to a pixel grid using a lightweight decoder or pyramid fusion module.

Computational Considerations

Full self-attention has O(N^2) complexity in the number of tokens, which becomes expensive for high-resolution images. This motivates hierarchical or windowed Transformers (e.g., Swin) that reduce complexity by restricting attention to local windows while still enabling cross-window communication via shifting.(Key references: Dosovitskiy et al., 2021; Vaswani et al., 2017.)

ViT applies a Transformer encoder directly to a sequence of fixed-size image patches. Each patch is linearly embedded and combined with positional information, then processed through stacked multi-head self-attention and feed-forward layers. ViT demonstrates that pure Transformer backbones can match or outperform CNNs when trained at scale, while providing a flexible token-based representation [10].

A key challenge for vision is the quadratic cost of global attention with respect to the number of tokens. Swin Transformer addresses this by restricting attention to local windows and introducing shifted-window attention to enable cross-window interaction. The result is a hierarchical, multi-resolution feature pyramid that resembles CNN behavior while retaining attention-based modeling capacity [3].

Summary of Prior Approaches in Robotic Grasp Prediction

In robotic grasping, many methods predict grasp candidates either as discrete rectangles or as dense maps over the image. Dense-map approaches (e.g., predicting grasp quality and orientation at each pixel) are attractive for real-time control because inference reduces to a global argmax over a quality map. Datasets such as Cornell Grasping Dataset and Jacquard provide annotated grasp rectangles to supervise such models [11,12]. Recent work also explores incorporating depth, segmentation, and learned priors to improve robustness under clutter and partial occlusions.
